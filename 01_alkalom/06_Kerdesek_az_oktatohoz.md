# Kérdések az oktatóhoz

Olyan pontok, ahol a kiírás nyitott, és egy korai válasz sok felesleges munkát spórolhat meg.
A válaszokat rögzítsük (dátummal) – ezek a dokumentáció feltételezés-fejezetébe is bekerülnek.

## Forrásadatok
| # | Kérdés | Válasz | Dátum |
|---|---|---|---|
| 1 | Mikor és hol kapjuk meg a minta Excel forrásállományt? Valós (anonimizált) vagy mintaadat lesz? | | |
| 2 | Ha nincs elég adat, generálhatunk-e saját tesztadatot a kapott szerkezet alapján? | | |
| 3 | Várható-e több Excel import a félév során (frissített forrásállomány), vagy csak egy kezdeti import? | | |
